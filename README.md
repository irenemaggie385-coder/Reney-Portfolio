# MedFile By Reney

A modern healthcare-focused portfolio and service platform built to help healthcare professionals and solo practitioners organize patient records, manage health information efficiently, and gain better insights through dashboards and summaries.

## About

MedFile By Reney provides digital health record organization and healthcare administrative support services including:

- Health records organization
- Patient information management
- Medical dashboards and summaries
- Data entry and documentation support
- Healthcare administrative assistance
- Basic health data analysis and reporting

## Features

- Responsive portfolio website
- Service showcase
- Clean and modern UI
- Contact section for inquiries
- Healthcare-focused branding

## Technologies Used

- HTML5
- CSS3
- JavaScript
